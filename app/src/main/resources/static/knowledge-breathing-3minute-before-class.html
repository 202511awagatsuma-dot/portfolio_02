レッスン前に使いやすい3分呼吸

忙しい日や緊張が強い参加者にも導入しやすい、3分構成の短い呼吸ワークです。姿勢の確認から始め、吸気と呼気の観察を経て、最後に吐く息を少し長めに整えます。

KEY POINTS

  • 1分ごとにテーマを分けると、初参加者でも迷いにくい。
  • 最初に接地感をつくることで、呼吸の安定が早くなる。
  • 呼吸を評価せず、気づきの言葉を中心に進める。
  • 最後は呼気を少し長めにして、クラスの集中を整える。

本文

3分呼吸は、レッスン冒頭の空気をそろえるための実用的な導入です。短時間でも順序を明確にすることで、参加者の注意が散りにくくなります。

1分目では、座位または立位で足裏や坐骨の接地を確認します。2分目は吸う息と吐く息の長さを観察し、無理にそろえず現在地を把握します。3分目で呼気をわずかに長くすることで、緊張から落ち着きへの切り替えをサポートできます。

この流れは、運動量の高いクラスにも静かなクラスにも接続しやすく、指導者側も再現しやすいのが利点です。時間がない日ほど、短く確実な導入として機能します。

実践手順

  • 1分目: 姿勢と接地感を確認し、肩や顎の力を抜く。
  • 2分目: 吸う息と吐く息の長さを観察し、呼吸のテンポを把握する。
  • 3分目: 吐く息を少し長めにし、全身の緊張がほどける感覚を確認する。

声かけ例

  • 導入: 「今日の呼吸を変える前に、まず今の状態を見ていきましょう」
  • 観察: 「吸う長さと吐く長さを、ただ数えるように確認します」
  • 仕上げ: 「吐く息をひとつ分だけ長くして、落ち着きを作ります」
